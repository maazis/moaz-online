# moaz.net

Source for my site: [moaz.net](https://www.moaz.net)

## Stack

Astro, Tailwind CSS, TypeScript, Bun, Cloudflare Pages, GoatCounter for analytics.

## Run it

```bash
bun install
bun run dev
```

Build: `bun run build` → output in `dist/`

Optional env: `PUBLIC_SPOTIFY_EMBED_URL` (Spotify embed is commented out for now)
